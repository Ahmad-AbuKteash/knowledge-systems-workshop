Nimbus API limits

Version: 2.1. Effective date: 2026-02-01. Supersedes api-previous.md. Owner: API team. Access scope: workshop-public.

Applicability: Nimbus order API from 2026-02-01 through 2026-08-31. From 2026-09-01, ../source-05/current-policy.pdf supersedes this limits guide. The separate webhook delivery guide remains applicable.

Orders

GET /v2/orders allows 120 requests per minute per API key. Excess requests return HTTP 429.

Retries

When provided, honor the Retry-After response header. Otherwise use exponential backoff with jitter.
