# Loan desk intake card

Record version: 1.0. Owner: IT Operations. Access scope: workshop-public.
Record type: checklist.

Published: 2026-10-14. Effective: 2026-10-14 onward.
The Nimbus loan desk records: request ticket, borrower, asset ID, issue timestamp, compliance check, and due date. Return staff confirm the charger and record damage separately from normal wear. A returned laptop must be reimaged before reassignment. The previous borrower's sign-out is not a substitute for reimaging. A 14-day loan does not authorize keeping a device beyond departure; the departure return process still applies. The desk card contains no customer records and should not include passwords.
