# Access request returned for missing purpose

Record version: 1.0. Owner: Identity Engineering. Access scope: workshop-public.
Record type: notice.

Published: 2026-10-06. Effective: 2026-10-06 onward.
The Nimbus access queue now returns requests whose purpose is only "same as teammate." Requesters must name the task, system, permission level, and required duration. A manager's approval confirms a business need but does not replace the application owner's approval. Emergency requests must identify the incident ticket and request the one-hour class explicitly. Screenshots containing MFA recovery codes must not be attached; Security can verify enrollment status without seeing the secret.
