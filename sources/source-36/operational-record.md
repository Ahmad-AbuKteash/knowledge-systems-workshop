# Training handout missing the diagram text

Record version: 1.0. Owner: Workplace Accessibility. Access scope: workshop-public.
Record type: review-record.

Published: 2026-10-15. Case date: 2026-10-14. Record type: fictional accessibility review.
A Nimbus training handout described a three-stage approval process only inside an image. The document had searchable body text but no text equivalent for the diagram. The reviewer requested the stage names, decision conditions, and responsible roles in the document body. Adding the label "approval diagram" alone would not convey the information. The document owner supplied a text version and retained the illustration as supporting material. This review is evidence of one correction, not proof that every Nimbus document is accessible.
